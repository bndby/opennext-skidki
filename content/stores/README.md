# Добавление магазина

Чтобы добавить предустановленный магазин, создайте отдельную папку в
`content/stores/`. Имя папки становится ключом бренда и должно быть в формате
`kebab-case`.

В папке должны находиться два файла:

```text
content/stores/example/
├── logo.svg
└── store.md
```

Поддерживаются логотипы `svg`, `png`, `webp`, `jpg` и `jpeg`. Имя файла должно
быть ровно `logo.<расширение>`, например `logo.png`.

## Формат `store.md`

```md
---
label: Название в списке
defaultStoreName: Название магазина
defaultCardColor: "#1976d2"
match:
  - "\\bмагазин\\b"
  - "\\bstore\\b"
---

Описание магазина в Markdown.
```

Поля frontmatter:

- `label` — название в списке предустановленных брендов;
- `defaultStoreName` — название, подставляемое в новую карточку;
- `defaultCardColor` — цвет карточки в формате `#RRGGBB`;
- `match` — один или несколько regex-шаблонов для автоматического определения
  бренда по названию магазина. Шаблоны регистронезависимые и понимают `\b`
  как юникод-границу слова (кириллица тоже считается буквами).

Текст после второго `---` сохраняется в сгенерированных данных как
`description`. Сейчас приложение его не показывает.

После изменения контента запустите:

```bash
npm run build:stores
```

Обычные команды `dev`, `build`, `deploy`, `upload` и `preview` запускают
генерацию автоматически. Скрипт проверяет frontmatter, regex и наличие ровно
одного логотипа, затем копирует логотип в `public/store-logos/` и обновляет
`src/lib/stores.generated.ts`.
